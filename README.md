# 🚀 Git Vibe Push (`vibe`)

**Git Vibe Push** — это минималистичная и стильная утилита на Python для быстрой автоматизации рутины `git add` -> `git commit` -> `git push` с авто-добавлением тематических эмодзи под ваш коммит.

---

## ✨ Возможности

- 🎨 **Стильный терминальный интерфейс** с красивыми рамками, цветами и анимацией (spinner).
- 🤖 **Автоматические эмодзи** на основе текста вашего коммита (`fix` -> 🐛, `feat` -> ✨, `style` -> 🎨 и т.д.).
- ⚡ **Одна команда** для полной синхронизации репозитория.

---

## 📦 Установка

### 🪟 Windows (CMD & PowerShell)

1. Убедитесь, что у вас установлен **Python 3.x** и **Git**.
2. Клонируйте или скачайте проект, например в папку `C:\tools\vibe-push`.
3. Создайте удобный алиас или батник для запуска по слову **`vibe`**:

#### Для CMD:

```cmd
reg add "HKCU\Software\Microsoft\Command Processor" /v AutoRun /t REG_SZ /d "doskey vibe=python Путь до вашего файла.py" /f
```

#### Для PowerShell (`$PROFILE`):
Откройте ваш профиль PowerShell (создайте, если его нет):
```powershell

notepad $PROFILE
```
Добавьте туда следующую функцию:
```powershell
function vibe {
    python "D:\projects\vibe-push\vibe-push.py" @args
}
```
*(Замените путь к `vibe-push.py` на ваш актуальный).* Перезапустите PowerShell.

---

### 🐧 Linux & 🍏 macOS

1. Убедитесь, что у вас установлен **Python 3** и **Git**.
2. Сделайте скрипт исполняемым и добавьте симлинк в `/usr/local/bin` (или в другую директорию из `PATH`):

Откройте терминал в папке проекта:
```bash
# Даем права на исполнение
chmod +x vibe-push.py

# Создаем симлинк с именем 'vibe' (требуются права sudo)
sudo ln -s "$(pwd)/vibe-push.py" /usr/local/bin/vibe
```
*Убедитесь, что в первой строке `vibe-push.py` (shebang) указан шебанг Python (при необходимости можно добавить `#!/usr/bin/env python3` в самый верх файла).*

---

## 🎯 Использование

Просто перейдите в директорию вашего Git-репозитория и вызовите команду:

```bash
vibe
```

Утилита спросит вас:
```text
╭── Git Vibe Push
├── Что сделали? ❯ добавил авторизацию
```

После ввода сообщения скрипт автоматически:
1. Добавит измененные файлы (`git add .`)
2. Создаст коммит с подходящим эмодзи (`✨ добавил авторизацию`)
3. Отправит изменения на удаленный репозиторий (`git push`)
